# Criando-uma-Ferramenta-de-Controle-de-Investimentos-com-Excel-DIO-

DIO Atividade

Simulador de Investimentos em Fundos Imobiliários

Projeto desenvolvido para o desafio da DIO “Simulador de Investimentos em Fundos Imobiliários”.

A proposta foi criar uma planilha no Excel que permita simular, de forma simples, como aportes mensais e uma taxa de rendimento estimada podem impactar o patrimônio ao longo do tempo.

Sobre o projeto

A planilha permite informar os principais dados da simulação, como:

Investimento inicial;
Aporte mensal;
Prazo do investimento;
Taxa de rendimento mensal estimada;
Valor da cota;
Dividend yield mensal estimado.

A partir dessas informações, os cálculos são feitos automaticamente por meio de fórmulas do Excel.

Funcionalidades
Cálculo do total investido;
Simulação da evolução do patrimônio mês a mês;
Cálculo dos rendimentos acumulados;
Estimativa de dividendos mensais;
Estimativa da quantidade de cotas;
Indicadores em formato de KPI;
Gráfico de evolução do patrimônio;
Gráfico comparando aportes e rendimentos;
Validação das principais entradas.
Estrutura

Simulador: área principal para inserir os dados e acompanhar os resultados.

Notas: explicação resumida das fórmulas e dos cálculos utilizados.

Tecnologias
Microsoft Excel
Fórmulas e funções nativas do Excel
Gráficos
Validação de dados
Formatação condicional
Observação

Este projeto possui finalidade educacional. Os valores apresentados são estimativas baseadas nos parâmetros informados pelo usuário e não representam garantia de rentabilidade ou recomendação de investimento.

Aprendizados

Durante o desenvolvimento, pratiquei a utilização do Excel para transformar cálculos financeiros em uma ferramenta interativa, trabalhando principalmente com fórmulas, referências entre células, validação de dados, organização de informações e criação de gráficos.
